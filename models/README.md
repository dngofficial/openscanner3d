# Local model checkpoints

No weights are bundled and no segmentation adapter is implemented yet. Follow the SAM 2 feasibility step in `../PLAN.md` before selecting a checkpoint.

Keep downloaded weights in this ignored directory. When a model is validated, record its source URL, exact identifier, SHA-256 hash, license, local filename, inference command, and measured memory/runtime in the project documentation. Runtime scans must not trigger internet downloads.
