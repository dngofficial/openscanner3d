How this works

Each processed frame produces an estimated-depth cloud. Different camera views are saved with RGB, depth and foreground masks. Finish computes camera poses with COLMAP, calibrates each usable depth map against shared 3D landmarks, and fuses the aligned points.

A normal webcam does not measure depth. Geometry and scale are estimates, and some clouds may not align. Move the camera around a stationary object with plenty of overlapping views. Results use arbitrary units.

The first model load downloads weights from Hugging Face. CPU inference works but can be slow; compatible PyTorch CUDA support speeds it up. COLMAP is required for final alignment.
