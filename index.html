Capture a useful photo set

  1. Keep the object still and move the camera around it. Aim for substantial overlap between neighboring views.
  2. Take a full circle at mid height, then another from a higher angle. Include close detail without changing zoom.
  3. Use soft, consistent light and a matte object with visible surface detail. Avoid motion blur, glare and blank surfaces.
  4. Keep the object centered. The reconstructed scene can include the background; this app does not isolate the object automatically.

A few unrelated angles will rarely align. Uploaded photos stay on this computer in the scan folder.
